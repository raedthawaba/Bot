# 🚀 AI Flutter Generator (نظام توليد تطبيقات Flutter بالذكاء الاصطناعي)

هذا المشروع هو نظام متكامل يعتمد على لغة **Python** لتحويل أوامر المستخدم باللغة الطبيعية (عربية أو إنجليزية) إلى تطبيقات **Flutter/Dart** جاهزة للتشغيل.

## 🌟 المكونات الرئيسية للنظام

1.  **AI Engine (محرك الذكاء الاصطناعي):** يقوم بتحليل أوامر المستخدم واستخراج العناصر المطلوبة (صفحات، أزرار، حقول إدخال).
2.  **Code Generator (مولد الكود):** يحول هيكل البيانات المستخرج إلى ملفات Dart منظمة داخل مشروع Flutter.
3.  **Execution Layer (طبقة التنفيذ):** مسؤولة عن تنظيم الملفات وتجهيزها للبناء والتشغيل.

## 📂 هيكل المشروع

```text
ai_flutter_generator/
├── ai_engine/          # محرك تحليل الأوامر
│   └── engine.py
├── code_generator/     # مولد أكواد Dart/Flutter
│   └── generator.py
├── execution_layer/    # طبقة التنفيذ والبناء
├── ui/                 # واجهة المستخدم (CLI/API)
├── dataset/            # قاعدة بيانات الأمثلة والتدريب
├── main.py             # نقطة البداية للنظام
└── README.md           # دليل الاستخدام
```

## 🛠️ كيفية الاستخدام

### 1. المتطلبات
- تثبيت **Python 3.x**
- تثبيت **Flutter SDK** (لتشغيل التطبيقات المولدة)

### 2. تشغيل النظام
قم بتشغيل الملف الرئيسي وأدخل وصف التطبيق الذي تريده:

```bash
python main.py "صفحة تسجيل دخول مع زر وحقل نص"
```

### 3. مخرجات النظام
سيقوم النظام بإنشاء مجلد باسم `generated_flutter_app` يحتوي على:
- `lib/main.dart`: الملف الأساسي للتطبيق.
- `lib/screens/`: مجلد يحتوي على صفحات التطبيق المولدة.

## 🔮 التطوير المستقبلي
