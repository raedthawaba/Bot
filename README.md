# 🚀 AI Flutter Generator (نظام توليد تطبيقات Flutter بالذكاء الاصطناعي)

هذا المشروع هو نظام متكامل يعتمد على لغة **Python** لتحويل أوامر المستخدم باللغة الطبيعية (عربية أو إنجليزية) إلى تطبيقات **Flutter/Dart** جاهزة للتشغيل.

## 🌟 الميزات الجديدة
- **دعم بوت تليجرام:** يمكنك الآن توليد تطبيقات Flutter مباشرة عبر التليجرام وإرسالها كملفات مضغوطة.
- **توليد تلقائي:** تحليل الأوامر وتوليد الكود وضغطه في ملف واحد وإرساله للمستخدم.

## 📂 هيكل المشروع

```text
ai_flutter_generator/
├── ai_engine/          # محرك تحليل الأوامر
│   └── engine.py
├── code_generator/     # مولد أكواد Dart/Flutter
│   └── generator.py
├── bot/                # معالج بوت تليجرام
│   └── handler.py
├── config.py           # ملف الإعدادات (يحتوي على التوكن)
├── main.py             # نقطة البداية للنظام (CLI أو Bot)
└── README.md           # دليل الاستخدام
```

## 🛠️ كيفية الاستخدام

### 1. المتطلبات
- تثبيت **Python 3.x**
- تثبيت المكتبات المطلوبة:
  ```bash
  pip install -r requirements.txt
  ```

### 2. تشغيل النظام
قم بتشغيل الملف الرئيسي واختر طريقة التشغيل:

```bash
python main.py
```
- اختر **1** للتشغيل عبر سطر الأوامر (CLI).
- اختر **2** لتشغيل بوت التليجرام.

### 3. مخرجات النظام
- **عبر CLI:** سيتم إنشاء مجلد `generated_flutter_app`.
- **عبر التليجرام:** سيصلك ملف `flutter_project.zip` يحتوي على كامل المشروع.

## 🔮 التطوير المستقبلي
- دمج نماذج لغوية كبيرة (LLMs) مثل GPT-4 لتحليل أوامر أكثر تعقيداً.
- دعم الربط مع Firebase و APIs تلقائياً.
